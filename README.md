# cs2114-project1-group23
Memorix 

User will open the "Quiz" file and run it. Through the console, user will be prompted to enter 4 cards with definition.

After the user created 4 cards, the user can either continue making more cards, or start the quiz. 

Cards order and the options will be randomly shuffled. After the quiz is over, the user has an option to repeat the quiz, but only with the problems they got wrong. 

User may repeat the quiz again with the problems they got wrong again. User may able to continue this process until the 10th attempt.
